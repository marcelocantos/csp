# TSan suppression file for CSP
#
# mbedTLS uses pthread mutexes for thread safety, but CSP's M:N scheduler
# migrates imps across OS threads.  TSan's fiber annotations correctly track
# happens-before for CSP's own synchronization, but pthread mutex operations
# are tracked per-OS-thread, not per-fiber.  When an imp acquires a mutex on
# thread T1 and releases it on T2 (after migration), TSan reports a false
# race.  These suppressions silence the mbedTLS false positives.
#
# See docs/todo.md and 🎯T9 for the full investigation.

race:mbedtls_*
race:psa_*
race:mbedtls_threading_mutex_*

# fake_clock::now() reads pending_ outside the mutex for a fast-path
# check.  The quiescence hook serializes the actual advance.  The
# unsynchronized read is benign — it may see a stale value, but the
# hook rechecks under the mutex.
race:csp::fake_clock::now
